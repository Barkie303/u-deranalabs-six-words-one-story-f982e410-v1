A complete story in exactly six words, written by `main.ts` to `/output/entry.txt`:

> He bought flowers weekly. Nobody visited.

A ritual, then the turn — and everything left unsaid is the reader's to fill in.

## Run

```sh
node main.ts
```

Reads `MAKEFUN_OUTPUT_DIR` (defaults to `/output`) and writes `entry.txt` there.
